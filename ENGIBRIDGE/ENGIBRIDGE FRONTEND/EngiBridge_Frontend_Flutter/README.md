# EngiBridge Flutter Frontend

## Included
- Login
- Signup
- Branch selection
- Dashboard
- Basics
- Theory
- Diagrams
- Practicals
- Question Bank
- Quiz
- Attendance
- Projects
- Soft Skills
- Interview Preparation
- Certificate
- Career / Company Connection

## Run
1. Install Flutter and Android Studio.
2. Open this folder in Android Studio or VS Code.
3. Run `flutter pub get`
4. Run `flutter run`

## Flask connection
Edit `lib/services/api_service.dart`.

Android emulator: `http://10.0.2.2:5000`
Physical phone: use your computer's local IP, such as `http://192.168.1.10:5000`.
